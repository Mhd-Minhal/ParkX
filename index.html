PROJECT OVERVIEW

WHAT IS PARKX?

PARKX is a student-built smart parking prototype created for a science fair. The project demonstrates how parking-space detection, RFID-based identification, visual indicators and a software application can work together to monitor and manage parking.

ℹ️ Our prototype is designed around exactly three parking slots: P01, P02, and P03.
01

DETECT

Detect whether parking spaces are occupied using dedicated proximity sensors.

02

IDENTIFY

Use RFID for contactless vehicle and authorized user identification at entry/exit points.

03

MANAGE

Display real-time parking availability and system information through the software application.

THE CHALLENGE

THE PROBLEM WE ARE SOLVING

Traditional parking management faces visibility and efficiency challenges.

⏳

Wasted Searching Time

Drivers waste time and fuel driving in circles searching for available parking spaces in congested lots.

👁️‍🗨️

Hidden Parking Availability

Parking availability is not visible before entering a facility, leading to unexpected traffic bottlenecks.

📋

Difficult Manual Management

Manual parking tracking relies on human error-prone counting, making real-time management difficult.

🚗

Blind Entry

Drivers enter parking areas without knowing whether a space is free, leading to frustration when lots are full.

PARKX demonstrates a technology-based approach to make parking information easier to understand and manage.

OUR APPROACH

HOW PARKX HELPS

Combining embedded sensors, RFID identification, and clear software displays.

Parking Detection

Dedicated sensors continuously monitor slot status to determine whether a vehicle is parked.

RFID Identification

Wireless RFID reader scans authorized tags at entry and exit barrier points.

Parking Status

Instant status indicators communicate free slots clearly to drivers and operators.

Entry Management

Automated entry barrier logic controls vehicle access based on slot availability and card validity.

Exit Management

Exit point scanning logs departing vehicles and immediately frees assigned slots.

Application Interface

Connected application interface displays clean occupancy metrics and system status.

PROCESS WORKFLOW

HOW IT WORKS

A simple step-by-step breakdown of the PARKX parking flow.

01

Vehicle Arrives

The vehicle approaches the PARKX entry point barrier.

02

RFID Identification

Driver presents an RFID tag to the reader for wireless identification.

03

Parking Spaces Checked

The system controller checks the status of the three parking slots (P01, P02, P03).

04

Available Space Is Indicated

If a slot is free, the system signals entry approval and indicates an available space.

05

Vehicle Parks

The vehicle parks in the assigned space. The parking sensor detects the vehicle and updates the slot state to occupied.

06

Vehicle Exits

When leaving, the vehicle passes the exit point. The system updates the parking status back to available.

ACCESS CONTROL

WHAT IS RFID?

RFID stands for Radio Frequency Identification. It allows a reader to identify an RFID tag wirelessly without requiring physical contact.

In PARKX, RFID is used to identify a vehicle or authorized user at controlled entry and exit points.

⚠️ IMPORTANT TECHNICAL DISTINCTION

RFID does NOT detect whether a parking space is occupied.

RFID is strictly used for identification at entry/exit points. A separate parking sensor installed in each slot is responsible for detecting whether a parking space is occupied.

💳 ➔ 📶 ➔ 🚧

RFID Identification Flow

1. User Taps RFID Tag
2. Reader Decodes UID
3. System Verifies User
4. Barrier Signal Sent
