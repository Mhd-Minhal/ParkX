FREQUENTLY ASKED QUESTIONS

Clear answers regarding the PARKX prototype implementation.

PARKX is a smart parking prototype combining infrared space detection, RFID identification, automated barrier control, and software monitoring.

Each slot contains a dedicated IR proximity sensor that measures infrared reflections to detect vehicle presence accurately.

Drivers scan an authorized RFID card or tag at the checkpoint. The reader decodes the unique ID and validates it with the controller to open the gate.

A precision servo motor physically raises the barrier arm when valid authorization is confirmed and closes it once the vehicle enters.

The companion web application communicates with the backend, allowing users to check live vacancies, choose durations, and view session status.

When the car triggers the slot sensor, the controller logs an entry timestamp and runs a countdown timer based on the booked session length.

If a vehicle remains parked beyond the booked duration, the system flags an overstay alert and computes supplementary demo parking fees upon exit.
