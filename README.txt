PARKX Launch Website
=====================

Files:
- index.html
- parkx-model.jpg

How to customize:
1. Open index.html in a text editor.
2. Find: const PROJECT_PASSWORD = "PARKX2025";
   Change PARKX2025 to the password you want.
3. Find: window.location.href="https://example.com";
   Replace it with your friend's real app/demo URL.
4. Upload index.html and parkx-model.jpg to a free static host.

IMPORTANT:
This password gate is suitable for a science-fair demo, but it is NOT secure authentication because the password is stored in the browser code. Do not use it to protect private/sensitive data.
